# Continuity Ledger — recap-meeting

## Goal
Phase 0 of a bilingual (EN–VI) live meeting recap app: capture Zoom/Teams web tab audio + mic,
live transcript (Deepgram) + live translation (Gemini → GPT fallback), saved to SQLite.
Done = T1–T6 in `docs/PLAN.md` ticked, `npm test` + `npm run typecheck` green, smoke test via
`tools/stream-file` prints transcript + translations, README explains how to run.

## Constraints
- Follow `docs/PLAN.md` (rules), `docs/ARCHITECTURE.md` (protocol + schema are contracts), `docs/DESIGN.md` (UI must not look AI-generated).
- TypeScript strict, small files/functions, every external service behind an interface.
- No git commits, no publishing online. Never print API key values.
- User is Vietnamese; UI copy in Vietnamese.

## Key Decisions
- 2026-10-21 Stack: npm workspaces, Next.js web + Node ws realtime, SQLite (WAL). User approved SQLite.
- STT Deepgram first (server proxy); AssemblyAI adapter (`universal-3-6-pro`, 2 mono sockets, VI/EN code-switching) implemented, off by default: set `STT_PROVIDER=assemblyai` + `ASSEMBLYAI_API_KEY` (untested against the live API). Translation Gemini primary, OpenAI fallback. Minutes OpenAI.
- Two audio channels: ch0 mic "Tôi", ch1 tab "Người khác"; Deepgram multichannel.
- Reuse/port parts of translation-ai (see `docs/REUSE-translation-ai.md`).
- Keys copied from translation-ai `.env` into repo `.env` (user asked to reuse that project's keys).
- 2026-10-21 T1: SQLite driver = **better-sqlite3 13** (builds/loads fine on Node 25.6; node:sqlite fallback not needed).
- 2026-10-21 T1: Tooling versions: TypeScript 6, ESLint 10 flat + typescript-eslint 8, Vitest 4 (root `projects`), Next 16.4 (Turbopack), React 19, Tailwind 4, zod 4.
- 2026-10-21 T1: TS `moduleResolution: Bundler`, extensionless relative imports; packages consumed as TS source via `exports: ./src/index.ts`.
- 2026-10-21 T1: ESLint enforces `max-lines` 300 and `max-lines-per-function` 50 (off in tests only).
- 2026-10-21 T1: Protocol offsets (`startMs`/`endMs`/`atMs`) and `seq` are validated as **non-negative integers** → producers (T2) must `Math.round` Deepgram float seconds×1000.
- 2026-10-21 T1: npm `-w` scripts run with cwd = workspace dir, so `DB_PATH`/`AUDIO_DIR` are resolved against the repo root (realtime `env.ts` does this; web must do the same).
